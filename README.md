# Abduhakimov Azizbek — Personal Portfolio

A modern, high-performance personal brand and portfolio website for **Abduhakimov Azizbek**, 19-year-old IT Mentor at IlmHub IT Education Center with 3+ years practical experience in robotics, programming, AI, and digital technologies.

## ✨ Features

- **4 Language Modes**: Full native support for Uzbek Latin (`UZ`), Uzbek Cyrillic (`ЎЗ`), Russian (`RU`), and English (`EN`) with instant switching and persistent `localStorage` memory.
- **Light / Dark Themes**: Carefully calibrated dark developer palette and clean light theme with CSS variables and system preference detection.
- **Top Bar Contract**: Clean 3-zone header with brand monogram wordmark, accessible navigation links, language dropdown, theme toggle, and quick contact action.
- **Hero & Status Cards**: Typographic impact statement, IlmHub mentorship badge, 3+ years experience, and responsive avatar visual with fallback.
- **Animated Statistics**: IntersectionObserver-powered counter metrics (3+ Years in IT, 250+ Students Mentored, 5+ Strong Projects, 1 Dedicated IT Mentor).
- **Categorized Skills**: Filterable tabs across Programming (Python, HTML, CSS), Robotics (Arduino, mBlock, Scratch), Mobile (MIT App Inventor, Android), AI (Prompt Engineering, AI Tools), and Digital Literacy.
- **Teaching & Mentoring**: Dedicated showcase highlighting project-based education and the visual flow: `IT Mentor → Student → Real Project`.
- **Project Showcase & Lightbox**: Interactive project cards with 4:3 preview images, clean tags, and detailed modal views.
- **Interactive Contact**: Direct communication channels (Phone, Telegram, Instagram, IlmHub) with copy-to-clipboard feedback and validated mailto form submission.
- **SEO & Accessibility**: Complete OpenGraph, Twitter Cards, Schema.org `Person` JSON-LD metadata, and WCAG AA contrast compliance.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 with custom CSS custom properties
- **Icons**: Lucide React
- **Motion**: Fluid CSS transitions + IntersectionObserver
- **Typography**: Plus Jakarta Sans & JetBrains Mono

## 🚀 Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build locally
npm run preview
```

## 📦 Push to GitHub

```bash
git init
git add .
git commit -m "Initial portfolio release for Abduhakimov Azizbek"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY
git push -u origin main
```

## 🌐 Deploy to Vercel

1. Push your code to your GitHub repository (using commands above).
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import your GitHub repository.
4. Framework preset will automatically detect **Vite**.
5. Click **Deploy**.
6. The included `vercel.json` ensures clean client-side routing fallback without any 404 errors.
